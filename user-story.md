# User Stories for SecondChance

## Story 1
**As a user, I want to register so that I can list my items.**
*   **Details and Assumptions:** The user must provide a valid email address and password.
*   **Acceptance Criteria:** The system creates a new user account in the database and returns a success message.

## Story 2
**As a user, I want to search for items by category.**
*   **Details and Assumptions:** Items in the database must have an assigned category.
*   **Acceptance Criteria:** The system filters the database and returns only the items that match the requested category.
